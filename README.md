# ⚔️ Quest for the Code: Interactive Developer Portfolio

> Every developer has a story. This is mine — one quest, countless lines of code, and endless possibilities.

Welcome to my interactive RPG-inspired developer portfolio!

I'm **Kadama Vamsi Krishna**, a Computer Science undergraduate at SRM Institute of Science and Technology, passionate about AI, Machine Learning, NLP, and Full-Stack Development.

Instead of a traditional portfolio, I built an interactive game-like experience where visitors can explore my skills, projects, experience, certifications, achievements, and contact information.

## 🎮 Live Portfolio

[**Explore Quest for the Code**]([YOUR_DEPLOYED_PORTFOLIO_URL](https://tsukishima07.github.io/quest-for-the-code/))

## ✨ Features

- **RPG-Inspired Interface:** Explore my portfolio through an interactive game-style world map.
- **Character Profile:** Learn about me, my background, and my developer journey.
- **Skills Forge:** Explore my technical skills with animated progress bars and ratings.
- **Battle Log:** Discover my experience and professional journey.
- **Artifact Hall:** Explore my projects and their technologies.
- **Scroll Library:** Browse my certifications.
- **Academy:** View my educational background.
- **Trophy Vault:** Discover my achievements.
- **Signal Tower:** Get in touch through the integrated contact form.
- **Live GitHub Integration:** Fetches public repository information, repository counts, and other GitHub statistics using the GitHub API.
- **Dynamic Audio System:** Procedurally generated background music and sound effects using the Web Audio API.
- **Interactive XP System:** Earn experience points while exploring different sections.
- **Responsive Design:** Designed to work across desktop and mobile devices.
- **Pixel-Art Aesthetic:** Retro gaming visuals, animations, glowing effects, and a starfield background.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/tsukishima07/quest-for-the-code
```

### 2. Navigate to the project directory

```bash
cd portfolio
```

### 3. Run the project

Open `index.html` in your browser.

Alternatively, use the Live Server extension in VS Code.

## 🎨 Customization

The portfolio is designed to make personalization simple.

Most personal information can be updated directly inside:

```text
portfolio-config.js
```

You can customize:

- Name, role and profile information
- Profile avatar and tagline
- Skills and skill ratings
- Projects and project links
- Experience
- Certifications
- Education
- Achievements
- Social media links
- Formspree contact form endpoint

The main JavaScript and CSS files handle the functionality and visual presentation.
